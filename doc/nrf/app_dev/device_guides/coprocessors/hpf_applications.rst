HPF applications
################

.. caution::

   The High-Performance Framework (HPF) support in the |NCS| is :ref:`experimental <software_maturity>` and is limited to the nRF54L15, nRF54LM20, nRF54LC10A, nRF54LV10A, and nRF7120 devices.

The |NCS| provides the following FLPR core applications built with the High-Performance Framework.
Each one implements the coprocessor side of an HPF driver and is selected through sysbuild, not built standalone.
